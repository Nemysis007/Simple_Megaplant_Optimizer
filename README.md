# Simple_Megaplant_Optimizer
A simple Plugin to optimize Megaplants using PCG


How to install.

Download the release file, extract and copy the folder into your projects "Plugins" folder.
If the Plugins folder doesn't exist in [your project name] then create the folder and copy the plugin into it.

Once installed open your project and open "Project Settings". Scroll down until you find the plugin listed. Click on it and then click the checkbox to enable. 
The second option is how much extra space to allow for the wind. If you're expecting to use high wind values increase the buffer amount. 
NOTE: If you set the wind values too high it will make megaplants behave strangely regardless of how high you set the buffer zone.
